# Data used in Hands-on Exercise 1A

Run `R/download-data.R` from the repository root to create the ignored
`data/raw` directory and download the source files used by the analysis.

- Master Plan 2014 Subzone Boundary (No Sea): data.gov.sg
- Pre-schools Location: data.gov.sg
- Cycling Path Network: data.gov.sg
- Singapore listings dated 29 June 2026: Inside Airbnb

The download script records the exact URLs and keeps the repository small.
Inside Airbnb asks users to link to its download page rather than redistribute
the raw file, so raw downloads are deliberately excluded from Git.
