# Shared Hunan inputs

Exercise 4B uses `handson4/data/geospatial/Hunan.*` and
`handson4/data/aspatial/Hunan_2012.csv`; no external absolute paths are needed.
The user-supplied CSV and SHP match the tracked copies by SHA-256 as checked on
2026-10-03. See `handson4/data/README.md` for the course source. Distance methods
use a copy projected to EPSG:32650, with sfdep's point-on-surface representation.
