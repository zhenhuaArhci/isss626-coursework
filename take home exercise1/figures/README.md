# Figures

All five PNG files are generated by `R/prepare.R` and `R/analysis.R` from the pinned inputs. Run from the website root or render the technical report to regenerate them. The slides use the same files.

- `study-area.png`: points and province boundaries.
- `monthly.png`: monthly events per calendar day.
- `planar-kde.png`: edge-corrected density at three bandwidths.
- `csr-envelope.png`: global uniform-placement benchmark.
- `fatal-pairs.png`: conditional fatal-event pair comparison.

Accidents: thaweewatboy/Kaggle, CC0 as listed. Boundary maps: geoBoundaries, based on OpenStreetMap contributors and Wambacher, ODbL 1.0. Full attribution and interpretation appear in the report.
