# Hunan course data

These original files are from Kam Tin Seong's public course repository:
https://github.com/tskam/ISSS626-AY2026-27Aug/tree/master/lesson/Lesson04/data

Retrieved on 19 September 2026. The shapefile contains 88 county polygons in
WGS 84. The CSV contains 88 county records and 29 attributes for 2012.
The shapefile components and CSV are kept together for offline reproduction.
Both Exercise 4 pages match on the unique `County` field and validate the
resulting feature count and GDPPC completeness. No input values were altered.
