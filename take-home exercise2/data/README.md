# Inputs and provenance

1. **ACLED:** course-provided `ACLED_Data_Myanmar_Jan2021-Sep2025.zip` containing one CSV. Place the ZIP in `take-home exercise2/data/raw/`, or leave the exact supplied filename in your Windows Downloads folder. An authorized CSV or ZIP can alternatively be supplied using `Sys.setenv(ACLED_MYANMAR_FILE="C:/path/input.csv")`. Original snapshot: 87,109 rows. See https://acleddata.com/methodology/acled-codebook.
2. **MIMU:** `Myanmar Township Boundaries_MIMU_PCodev9.4.zip`, downloaded 2026-10-23 from https://data.themimu.info/en/dataset/myanmar-administrative-boundary. Choose the township ZIP resource, not district/ward data. Save locally as `take-home exercise2/data/raw/mimu-v94.zip`, leave the official filename in Downloads, or set `MIMU_TOWNSHIP_FILE` to its path. The direct resource is https://data.themimu.info/api/files/resources/361513c4-22d4-4f85-9920-1a9afc2ac1cb/myanmar-township-boundaries-mimu-pcodev9-4.zip. Browser download may be necessary because the site challenges scripted downloads. Layer: `mmr_polbnda_adm3_250k_mimu.shp`, 330 townships, `PCode_V=9.4`. Archive Metadata.txt incorrectly says district/Admin2; the actual layer schema and township PCode cardinality were verified. Terms: https://themimu.info/mimu-terms-conditions.

MIMU and its source contributors retain attribution. Boundaries and names do not imply endorsement or acceptance by the UN or MIMU. The dataset is provided as-is; source uncertainty remains. Raw archives, geometries and event-level intermediate files are excluded from Git and site resources. Only analytical static figures, scripts, provenance and township-level aggregates are published. Review the source terms before reuse or redistribution; no raw-data licence is granted by this repository.

`input-checksums.csv` records SHA-256 hashes and sizes of the exact archives used. The code checks schema, version, parsing, dates, duplicate IDs, coordinate validity and polygon matches. Changing an input recomputes its checksum and invalidates the pipeline fingerprint. No expiring signed URL is stored.

The main outcome includes Battles, Explosions/Remote violence, and Violence against civilians. It excludes other event types and location-precision code 3. Polygon containment is authoritative; unmatched coordinates are not snapped to land. The complete cube retains all 330 × 57 cells. See the technical report for audit counts, statistical choices and limitations.
